# ぬい活スポット検索 - 機能仕様・処理詳細

## 1. 概要

推しぬい（ぬいぐるみ）と一緒に訪問できるカフェや撮影スポットをユーザー投稿型で共有・検索できるWebプラットフォーム。

---

## 2. システム構成・技術スタック

- **フロントエンド / フレームワーク**: Next.js (App Router, TypeScript)
- **スタイリング**: Tailwind CSS
- **マップライブラリ**: Leaflet / React-Leaflet (OpenStreetMap)
- **バックエンド / DB**: Supabase (PostgreSQL)
- **認証 / 認可**: Supabase Auth / Row Level Security (RLS)
- **ファイルストレージ**: Supabase Storage (バケット名: `spot-images`)

---

## 3. DBデータ構造 (`spots` テーブル)

| カラム名       | 型            | 説明                                                         |
| :------------- | :------------ | :----------------------------------------------------------- |
| `id`           | `uuid`        | スポット識別子 (Primary Key)                                 |
| `name`         | `text`        | スポット名                                                   |
| `slug`         | `text`        | URL用識別子                                                  |
| `description`  | `text`        | スポットの概要・説明文                                       |
| `address`      | `text`        | 所在地（住所）                                               |
| `latitude`     | `numeric`     | 緯度                                                         |
| `longitude`    | `numeric`     | 経度                                                         |
| `push_colors`  | `text[]`      | おすすめ推しカラーラベル配列（例: `['#ef4444', '#ec4899']`） |
| `image_url`    | `text`        | アップロード画像の公開URL (Nullable)                         |
| `is_published` | `boolean`     | 公開状態フラグ                                               |
| `created_at`   | `timestamptz` | 登録日時                                                     |

## 4. 機能一覧および処理詳細

### ① スポット一覧表示 & インタラクティブマップ

- **カード型一覧表示**:
  - 登録されているスポットを2カラムグリッドでカード化。
  - **画像プレースホルダー**: 画像（`image_url`）が存在しない場合、グラデーション背景＋アイコン（🧸 `No Image`）を表示して崩れを防止。
  - **カラーバッジ表示**: 各スポットに登録された推しカラーコードを日本語名（「赤」「ピンク」など）とカラーコード色付きポッチ（`ColorBadge` Component）に変換して描画。
- **マップ連携 (`MapWrapper`)**:
  - スポットの緯度・経度情報に基づき Leaflet マップ上にピン（Marker）を配置。
  - フィルタリング結果に連動してマップ上のピンもリアルタイムに絞り込まれる。

### ② 検索 & 推しカラーフィルター機能

- **キーワード検索**:
  - 入力されたテキストに基づき、スポット名（`name`）・説明（`description`）・住所（`address`）をリアルタイムに部分一致（あいまい）検索。
- **推しカラー絞り込み**:
  - 登録されている全スポットから使用中のカラーコード（`push_colors`）を抽出してフィルターボタンを動的生成。
  - ボタン選択時にアクティブ状態（`ring-2 ring-pink-400`）を強調表示。
  - 単一カラー選択または「すべて」切り替えによるリアルタイムデータ絞り込み。

### ③ スポット追加・画像アップロード機能 (`/add`)

- **基本情報入力**:
  - スポット名、概要、住所、位置情報（緯度・経度）の入力。
  - カラー選択欄はカラーコード直接入力ではなく、あらかじめ用意されたカラープリセット（赤・ピンク・青・緑など）から直感的に複数選択可能。
- **画像アップロード処理**:
  - フォームからの画像選択時、Supabase Storage API を経由して `spot-images` バケットへ直接ファイルをアップロード。
  - アップロード成功後に発行される Public URL（`getPublicUrl`）を取得し、`spots` テーブルの `image_url` カラムに保存。

---

## 5. Storage & 権限設計 (RLS Policy)

- **バケット設定**:
  - バケット名: `spot-images` (Public Access: 有効)
  - ファイルサイズ制限: 50MB / 1ファイル
- **Storage RLS Policies**:
  - **`SELECT` (全ユーザー可)**: 画像の公開参照を許可（`bucket_id = 'spot-images'`）。
  - **`INSERT` (全ユーザー可)**: 匿名を含む投稿ユーザーからの画像アップロードを許可。
